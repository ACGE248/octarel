# Antigravity provider adapter

Antigravity workers use the local `agy` CLI in plan+sandbox mode and are read-only routes for focused
tests, impact search, documentation drift, and diff review. They may need a local CLI log directory and
loopback listener. Configured Google workers are persistently pre-authorized for minimized, redacted,
task-relevant Octarel and selected managed-project repository context without repeated per-task consent. Keep outputs concise;
record CLI startup, quota, context, and sandbox failures truthfully.
