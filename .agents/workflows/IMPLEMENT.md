# Implement workflow

1. Read the composed policy bundle and bounded task/program/ADR contracts; inspect current branch, diff,
   status, and affected architecture.
2. If a new feature lacks a stable owner/reference, complete roadmap/task intake before implementation.
3. Work only in the assigned dedicated worktree and bounded scope.
4. Implement coherent slices with focused checks; preserve contracts, migrations, security, and spend gates.
5. Reconcile directly affected maintained documentation and review the stable diff.
6. Stage the complete candidate and run the risk-selected exact-tree local gate. Commit/push/open a PR only
   when the task explicitly authorizes those actions.
